Entry for the [make.fun bounty "Tell a Whole Story in 32 Characters"](https://make.fun/bounty/u-xvader-tell-a-whole-story-in-32-characters-f86dd978) ($2 USDC, winner-takes-all).

The entry is a single Wi-Fi network name of exactly 32 characters — a three-beat
divorce micro-story: she takes the kids and the dog, and all he walks away with
is the Wi-Fi.

```
She took 2 kids+dog! I kept WiFi
```

`main.py` (Python standard library only) writes the entry to `/output/entry.txt`.
Run it with `python3 -P -s main.py`.
